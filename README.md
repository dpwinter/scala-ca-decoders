# SCALA and Harrington cellular-automaton decoders

This repository contains the implementations and numerical analysis code used for the SCALA cellular-automaton decoder study.

It includes one- and two-dimensional implementations of

- **SCALA1D**
- **SCALA2D**
- **Harrington1D**
- **Harrington2D**

for repetition and toric codes under code-capacity and phenomenological noise.
